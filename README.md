# 施工管理システム(株式会社メディコム)

他社(請負会社)が現場で施工写真をアップロードし、自社が案件・金額・入金/支払を管理するための Web アプリです。
まずは蓄電池工事から始め、他の工事にも広げられる作りにしています。

| ファイル | 使う人 | 内容 |
|---|---|---|
| `index.html` | 請負会社 | ID・パスワードでログイン → 自分の現場 → 写真チェックリスト(撮影・送信) |
| `admin.html` | 自社(店主) | 案件・金額・入金日/支払日の管理、写真の確認、請負会社のアカウント発行 |
| `config.js` | — | Supabase の接続先と公開キー(公開してよい値。秘密情報は置かない) |
| `style.css` | — | 共通の見た目 |

## データの置き場所と守り方

- データは Supabase の `pos-system` プロジェクト内の専用スキーマ `kouji`(API に公開されない)に置く。写真は非公開バケット `kouji-photos`。
- 請負会社は Supabase Auth を使わず、専用の ID/パスワード(`kj_login`)で入る。ブラウザからテーブルを直接読むことはできず、決まった関数(`kj_*`)だけを通る。
- **金額(請負金額・工事代金・入金日・支払日)と施主名は、請負会社向けの関数から一切返さない。**
- 請負会社は「自分の現場の写真」だけを見て、送れる。5回続けて間違えると15分ロック。無効化・パスワード再発行で、ログイン中の端末もすぐ使えなくなる。
- 写真の送信は Edge Function `kouji-api`(JPEG のみ・1枚6MBまで)。端末側で長辺1600pxに縮小してから送る。
- 管理画面は、POS と同じ店主アカウントでログインし、データベース側でも店主かを確認する(店主以外は拒否)。
- 注意: このデータベースの環境では「削除(DELETE)を含む変更」が自動で取り消される。そのため、写真・案件の削除機能は作っていない(ログアウト/無効化は「有効期限を今に更新」で行う)。

## 蓄電池工事の必要写真(7項目)

設置写真 / 引きの設置全景 / パワコン接続部確認写真 / ドングルシリアルナンバー写真 / ドングル通信確認写真 / 通電後パワコン画面写真 / 出庫指示書写真
(`kouji.photo_requirements` に工事の種類ごとに登録。他の工事を追加するときは、`kouji.work_types` と必要写真の行を足す)

## 公開手順

1. GitHub の `Settings → Pages` で、Branch を `main` / `/ (root)` にして保存。
2. 公開URLは `sekou.medicom.co.jp`。DNS に **CNAME レコード**(ホスト名 `sekou` → 値 `yskm10.github.io`)を追加済みであること(営業担当が管理)。リポジトリ直下の `CNAME` ファイルにサブドメイン名を書いてある(消さないこと)。Pages の設定で「Enforce HTTPS」を有効にする。
3. 請負会社には `https://sekou.medicom.co.jp/` を、自社は `https://sekou.medicom.co.jp/admin.html` を使う。

## 運用

- 請負会社を追加: 管理画面 →「請負会社のアカウント」→「会社を追加」。表示された案内文をコピーして先方に伝える(パスワードはその画面を閉じると二度と見られない)。
- 案件を追加: 管理画面 →「案件」→「案件を追加」で請負会社を選ぶ。
- 写真が増えると Supabase 無料枠(ストレージ 1GB)に近づく。縮小後の1枚は数百KB程度なので、目安は数千枚。
